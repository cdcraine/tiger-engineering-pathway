# Tiger Engineering Pathway v3

A University of Memphis-inspired academic planning prototype for engineering students. It is a planning supplement, not an official degree audit.

## Run
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

## Main workflow
1. Student Setup
2. Course Catalog
3. Degree Requirements
4. Transcript Entry
5. Prerequisites
6. Degree Audit
7. Priority Engine
8. What-If Analysis
9. Semester Planner / Auto Plan
10. Risk Analysis
11. Data Center

The UI uses University of Memphis blue/gray-inspired styling and text branding. For official logo use, obtain the approved UofM logo/departmental identity from University Marketing and Communications and place it in `static/images/`; do not recreate or alter official marks.
